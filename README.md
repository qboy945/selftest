# 緣來喝茶自我檢測

人格特質與中醫體質自我檢測。純前端、純本機計算，不上傳任何資料。

## 兩個檢測

**人格特質**（20 題）：五大向度 — 開放性、盡責性、外向性、親和性、情緒敏感度。
含 5 題反向題，避免固定作答傾向。

**中醫體質**（24 題）：八種偏向 — 氣虛、陽虛、陰虛、痰濕、濕熱、血瘀、氣鬱、特稟。
簡化版，非完整量表。多數人會同時呈現數種偏向。

## 界線

- 結果為生活參考，**非醫療診斷**
- 不提供藥物、方劑、療效或治療建議
- 建議只寫作息、飲食方向、就醫時機
- 資料只留在使用者裝置
